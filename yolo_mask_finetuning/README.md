# YOLO 口罩检测微调学习

结合本地口罩检测项目，从数据和标签开始，逐步理解微调。沿用已有的 CNN、目标检测与 YOLOv1 知识，一次学习一个问题。

从第七课起以完成口罩检测微调与部署为主，理论以理解操作和判断结果所需的程度为限，不再展开底层损失推导。

## 当前笔记

- [01 从真实图片到 YOLO 训练标签](01_从真实图片到YOLO训练标签.ipynb)：从下载数据集中的一张真实图片出发，学习类别编号、边界框归一化、坐标还原，以及全图标签坐标与 YOLOv1 格内偏移的区别。
- [02 训练集与验证集：怎样判断模型真的学会了](02_训练集与验证集_怎样判断模型真的学会了.ipynb)：理解参数学习与评估的区别、先划分再增强、来源泄漏、类别分布，以及作者权重与重新划分验证集的关系。
- [03 预训练、冻结与微调：参数从哪里开始](03_预训练冻结与微调_参数从哪里开始.ipynb)：区分参数起点、可训练范围和学习率，理解类别变化时的权重迁移，并对照本地 YOLOv5 的加载逻辑。
- [04 YOLOv5 三个检测尺度：大小人脸怎样检测](04_YOLOv5三个检测尺度_大小人脸怎样检测.ipynb)：通过空间网格示意图理解 P3、P4、P5、步长与小目标检测，区分三个尺度与每处三个 anchor，并核对当前权重元数据。
- [05 Anchor 是什么：参考模板与预测框](05_Anchor是什么_参考模板与预测框.ipynb)：用示意图区分宽高模板、人工真实框与预测框，理解每个 anchor 对应的三类口罩预测为什么有八个输出。
- [06 YOLOv5 目标分配：一个真实框怎样教多个预测](06_YOLOv5目标分配_一个真实框怎样教多个预测.ipynb)：对照本地 build_targets，用算例理解宽高匹配、中心网格与邻近位置，以及一个目标对应多个正样本的含义。
- [07 面向完成项目的微调流程](07_面向完成项目的微调流程.ipynb)：收拢实践路线，理解必要训练参数、短程试跑、结果检查与权重部署，记录本地数据检查发现的重复图片与超界框。
- [08 实践记录：口罩训练数据准备完成](08_实践记录_口罩训练数据准备完成.ipynb)：记录生成的 682/171 张训练与验证图片、重复分组、坐标修正、画框检查和复查入口。
- [09 实践记录：第一次三轮微调完成](09_实践记录_第一次三轮微调完成.ipynb)：记录通用 YOLOv5s 起点、实际训练参数、逐轮指标、新权重加载检查与短程训练的局限。
- [10 实践记录：扩充数据并开始 30 轮微调](10_实践记录_扩充数据并开始30轮微调.ipynb)：记录合并 Medical Mask 后的 4,316/1,081 张训练与验证图片、筛除原则、类别加权抽样与自动评估流程。
- [11 YOLOv5s 逐层结构：从图片到三个检测输出](11_YOLOv5s逐层结构_从图片到三个检测输出.ipynb)：对照本轮实际训练日志，解释 0–24 模块、各层输出形状、双向多尺度融合、Detect 与全模型微调。

## 当前进度

已有十一课笔记。原训练数据为 682 张训练图片、171 张验证图片；从官方通用 YOLOv5s 预训练权重完成了 3 轮微调，生成 best.pt、last.pt 并完成加载与图片检测检查。原始压缩包、作者权重与网页默认配置保留。

扩充数据后的 30 轮训练与自动评估已完成：在同一批原 171 张验证图片上，mAP@0.5 从 22.48% 提升到 77.97%；扩充验证集 mAP@0.5 为 78.20%。佩戴不规范召回率为 46.33%，仍有明显改进空间。当前已提供“启动微调演示.cmd”，显式加载自己的 30 轮模型，原作者权重保留。

向老师展示时，可打开原项目 runs/train/mask_expanded_30epochs/展示报告.html，按“任务与数据、前后指标、训练曲线、现场演示、问题案例”的顺序讲解。报告包含三类成功样例和两个失败样例；验证集 mAP 不能称为准确率。
