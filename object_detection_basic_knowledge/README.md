# 目标检测基础知识

本目录位于 CNN、Transformer 基础之后，YOLO 与 DETR 之前。

目标不是立刻实现某个检测模型，而是先建立一条完整、连贯的目标检测主线：模型面对什么问题、标注怎样表示、预测怎样评价、训练时怎样分配目标，以及为什么传统检测器需要 NMS。

## 学习原则

- 一次只解决一个核心问题。
- 先理解任务和数据，再学习模型结构。
- YOLO 只作为传统单阶段检测器的代表，不追逐版本差异。
- 理解传统检测流程以后，再回到 DETR，比较它改变了哪些环节。

## 学习主线

```text
图像分类、定位与目标检测
-> 边界框与坐标表示
-> IoU：两个框有多接近
-> 分类预测与边界框回归
-> 正样本、负样本与目标分配
-> 为什么产生重复预测
-> NMS 如何删除重复框
-> Precision、Recall、AP 与 mAP
-> 用简化 YOLO 串起完整检测流程
-> 传统检测器的复杂性
-> 回到 DETR：集合预测怎样重写流程
```

## 当前笔记

- `01_目标检测是什么_从分类到定位.ipynb`：从一个生活场景出发，区分图像分类、单目标定位和目标检测，理解类别、边界框、坐标格式、归一化以及“多个目标构成无序集合”。
- `02_IoU边界框重叠度.ipynb`：从交集与并集出发，逐步计算两个 `xyxy` 框的 IoU，理解取值范围、阈值、特殊情况、常见错误与普通 IoU 的局限。
- `03_分类与边界框回归.ipynb`：理解一条检测结果为什么同时包含离散类别与连续坐标，跟踪双预测头、输出形状、分类损失、框损失及其共同反向传播。
- `04_正样本负样本与目标分配.ipynb`：通过 2 个真实目标与 6 个候选预测的 IoU 对照表，理解正样本、负样本、忽略样本、一对多分配和一对一分配。
- `05_重复预测与NMS.ipynb`：从一对多监督产生重复框讲起，用两只狗和一只猫的例子逐轮执行分数筛选与按类别 NMS。
