# ViT 亮点与批判注记

## 一、创新点

1. **把"Transformer 用于视觉"这条路上最朴素的做法做到底**：不设计特殊注意力，直接 patch+标准 Transformer，把复杂度问题交给"patch 化把序列长度压到 N=HW/P²"。
2. **彻底移除 CNN 归纳偏置**：除切 patch 与位置插值外，不注入平移等变性/局部性/二维邻域结构，把空间关系全留给数据去学——这是对"卷积先验是否必要"的正面回答。
3. **核心论断的提出与验证**："large scale training trumps inductive bias" 用 §4.3 的数据拐点实验（9M/30M/90M/300M 子集）给出清晰证据：小数据 ResNet 赢、大数据 ViT 反超。

## 二、方法巧思

- **Patch 当 token**：把图像视为"句子"、patch 视为"词"，直接复用 NLP 全套 Transformer 实现——"开箱即用"是工程上极重要的取舍。
- **借鉴 BERT `[class]` token**：而非用全局平均池化（GAP），与 NLP 习惯一致；附录还专门讨论 CLS vs GAP（v2 修订新增）。
- **位置嵌入 2D 插值**：微调到高分辨率时保持 patch 不变、对预训练位置嵌入做双线性插值——这是 ViT"仅有的两处手动 2D 归纳偏置"之一，巧妙兼顾了灵活性。
- **位置嵌入自动学到 2D 拓扑**：§4.5 证明可学习 1D 位置嵌入自发涌现距离/行列/正弦结构，解释了为何手工 2D 嵌入无增益——很有说服力。

## 三、意外结果

- **混合模型仅在小算力下略优**（§4.4）：本以为 CNN 局部处理在任何尺寸都有助，结果大模型上 CNN 前端优势消失——意外支持"卷积先验在小算力才必要"。
- **ViT 未饱和**（§4.4）：性能-算力曲线在所试范围内仍在上升，预示更大 ViT 还有空间（后被证实）。
- **自监督掩码 patch 预测已达 79.9%**（§4.6）：虽落后监督约 4%，但已显示潜力——这一"留待未来"直接催生了 MAE。

## 四、局限

1. **数据饥渴**：小数据上过拟合、不如 ResNet；"击败 SOTA"依赖 JFT-300M（私有 303M 图、18k 类）这一普通研究者难获取的数据集。
2. **算力门槛**：ViT-H/14 预训练仍需 2.5k TPUv3-core-days，非小实验室可及；公平小数据对比下 ViT 反而更差（§4.3）。
3. **任务范围窄**：只做图像分类，未触及检测/分割——论文坦承是"挑战之一"（§5）。
4. **自监督未成熟**：掩码 patch 预测仍落后监督 ~4%，对比式预训练未做。
5. **高分辨率序列长**：微调到高分辨率时序列变长，对显存压力大；论文用 Polyak 平均与高分辨率微调缓解，但未给高效注意力方案（后由 Swin 等解决）。

   **为什么算力/显存压力会连累大图里的小物体识别**：
   - 自注意力是序列长度 N 的二次方复杂度，而 N 随分辨率线性增长：大图 → patch 变多 → 序列变长 → 计算和显存按 N² 暴涨，很快爆显存。
   - 为省资源只能二选一：① 下采样大图（分辨率降低，小物体本就几个像素，再压缩就只剩 1 个甚至不到 1 个 patch，信息基本丢失）；② 增大 patch 尺寸（等效降低有效分辨率，小物体细节被抹平）。
   - 结果：小物体最终只对应极少数 token，在全局注意力里被淹没，难以保留足够的局部细节，导致漏检/误识别。
   - 一句话：算力限制逼你用粗粒度特征表示大图，而小物体恰恰需要细粒度的局部特征。

## 五、开放问题（论文自述 + 派生）

- ViT 用于检测/分割？（→ DETR/DETA、Swin 等回应）
- 自监督预训练如何追平监督？（→ MAE/DINO 兑现）
- 继续扩展到更大？（→ ViT-G/22B 等回应）
- 高效注意力以处理高分辨率？（→ Swin 窗口、线性注意力等）

## 六、可质疑性注记

- **"击败 SOTA"的公平性**：ViT-H/14(88.55%) 仅以 0.15% 优势超 Noisy Student(88.4%)，且 ViT 用了 JFT-300M（含更多数据/标签）而 Noisy Student 用 ImageNet+去标签 JFT——比较并非完全同条件。论文 §4.2 也提醒"预训练效率受多因素影响"。读者宜把"超越"理解为"在同一大数据量级下有竞争力"，而非严格同等条件胜出。
- **位置嵌入涌现 2D 结构的证据**为可视化分析，属定性证据，未做消融定量证明"手工 2D 嵌入确实无必要"——虽附录 D.4 给了消融，但"涌现"与"性能"之间的因果仍偏解释性。
- **§4.3 数据拐点结论**基于 few-shot 线性准确率（省算力），与最终微调性能可能不完全一致——论文也承认 few-shot 仅为快速评估。
- **算力比较**以 TPUv3-core-days 计，但不同架构在不同硬件上效率不同，该指标对"架构效率"的反映有近似性。

## 七、学术品味总评
ViT 的价值不在于"第一个把 Transformer 用在视觉"（Cordonnier 2020 等更早），而在于**大胆押注"朴素 + 大数据"并用充分实验证明归纳偏置可被规模取代**——这是一次成功的范式押注，其后续影响（DeiT/Swin/MAE/CLIP）远超论文本身的分类精度。
