# CBAM 注意力机制学习导航

本目录单独记录 CBAM 的概念学习，建立在 CNN 特征图、池化和张量形状等知识之上。

## 当前笔记

- `01_CBAM注意力机制入门.ipynb`：理解 CBAM 的作用、通道注意力与空间注意力，以及输入和输出的形状变化。

- `02_CBAM通道注意力详解.ipynb`：逐步理解通道池化、共享 MLP、权重生成、广播相乘和参数更新。

- `03_CBAM空间注意力详解.ipynb`：逐步理解沿通道池化、拼接、多通道卷积、空间权重生成和广播相乘。

- `04_梨叶分类论文与MobileNetV2结构.ipynb`：结合论文与 torchvision 结构，理解预训练骨干、CBAM 接入位置和对照实验。

后续可以根据学习进度，逐步深入完整模块和实现。
