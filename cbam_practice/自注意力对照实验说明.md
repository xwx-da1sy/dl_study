# CBAM 与串联自注意力对照实验

本实验比较基础 CNN、CNN + 教学版 CBAM、CNN + 串联通道和空间自注意力。三组使用相同骨干结构和初始参数、分层数据划分、每轮数据顺序与增强、优化器和训练轮数。实验代码在 [compare_self_attention.py](compare_self_attention.py)。

## 改造结构

在 CNN 每个块之后，改造版依次应用两个单头 Q/K/V 自注意力模块：

1. **通道自注意力**：每个通道是一条 token，包含该通道全部空间位置；线性层生成 16 维 Q、K、V，计算通道间注意力，输出映射回空间维度，再通过可学习缩放系数与输入相加。
2. **空间自注意力**：每个空间位置是一条 token，包含该位置的全部通道；线性层生成 Q、K、V，计算空间位置间的全局注意力，再通过可学习缩放系数与第一阶段输出相加。

这些残差和缩放系数是实验设计选择；CBAM 则计算权重并逐元素相乘。两者计算方式、参数量和计算开销均不同，因此结果体现的是整个变体的差异，不能归因于某个单独因素。通道线性层依赖固定特征图尺寸，本实验三个块的尺寸分别为 16、8、4。这个变体不是 DANet，也不是原论文结构。

## 运行

```powershell
python cbam_practice/compare_self_attention.py
```

默认种子 42、训练 5 轮、batch size 128。最佳轮次由验证集选择，三个模型各在测试集评估一次。结果写在 `self_attention_results/`，包含训练和验证耗时、训练与验证期间 PyTorch 峰值分配显存、参数量及测试指标。峰值分配显存不等于显卡的全部占用，也不含测试阶段。再次运行会覆盖同名结果。

单次短训练结果不能证明普遍效果；参数量不同意味着这不是等参数量对照。
