# CIFAR-10：CBAM 对照实验结果

本次实验使用随机种子 42，每组训练 5 轮，按验证集准确率选最佳轮次，在独立测试集评估。数据与配置见 [实验说明](README.md)。

| 指标 | 基础 CNN | CNN + CBAM |
|---|---:|---:|
| 最佳轮次 | 5 | 5 |
| 最佳验证准确率 | 65.36% | 69.46% |
| 测试准确率 | 64.29% | 67.77% |
| 测试损失 | 1.0025 | 0.9074 |
| 可训练参数量 | 94,762 | 97,982 |
| 5 轮训练及验证时间 | 44.5 秒 | 46.2 秒 |

本次 CBAM 组测试准确率高 3.48 个百分点，同时多出 3,220 个参数。时间为此次设备上的测量，包含每轮验证，受 GPU 预热等因素影响。

实验组首个 batch 中，第一个 CBAM 的 MLP 第一层权重梯度范数约为 0.00797，空间卷积权重梯度范数约为 0.03223；它们非零，表明该次反向传播中两处参数收到梯度。

两组使用相同的基础 CNN 初始化、分层划分与训练设置。结果仅来自单次种子、短训练和一个小型 CNN：它说明这次实验中 CBAM 组表现更好，不能据此断言 CBAM 对所有任务或配置都有效，也不能直接与原论文结果比较。

完整逐轮结果见 [results.json](results/results.json)。
