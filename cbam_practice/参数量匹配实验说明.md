# 参数量匹配对照实验

目的：将基础 CNN 加宽到与串联自注意力模型参数量接近，再比较分类表现，考察增加模型容量能否解释之前的差距。

| 模型 | 每层输出通道 | 参数量 |
|---|---|---:|
| 加宽 CNN | 47、94、188 | 202,627 |
| 串联自注意力模型的 CNN 骨干 | 32、64、128 | 203,664（包括自注意力） |

参数量差 1,037，约为自注意力模型的 0.51%。加宽 CNN 的层数、卷积核大小、池化和分类头形式沿用原基础 CNN，但参数形状不同，无法与自注意力模型使用逐元素相同的骨干初始参数。

两组沿用 CIFAR-10 的 45,000 / 5,000 分层训练与验证划分、10,000 张测试集、随机种子 42、随机裁剪与翻转、Adam、学习率 0.001、batch size 128 和 5 轮训练；根据验证准确率选模型，再在测试集评估。此前测试集已被用于探索，这里也属于探索性实验。

准备好后在项目根目录运行：

```powershell
python cbam_practice/compare_parameter_matched.py
```

可传入 `--epochs`、`--batch-size`、`--seed`。结果保存在 `parameter_matched_results/`，重复运行会覆盖同名结果；不会覆盖此前实验。训练和验证耗时受机器负载影响，峰值显存是 PyTorch 已分配内存。

参数量接近不代表计算量、结构或优化难度相同；单个种子和五轮训练不能证明机制的普遍优势。
