# 参数量匹配实验结果

CIFAR-10 单次种子 42、各训练 5 轮，按验证集准确率选最佳轮次。配置和结构见 [实验说明](参数量匹配实验说明.md)。

| 指标 | 加宽 CNN | 串联自注意力 |
|---|---:|---:|
| 参数量 | 202,627 | 203,664 |
| 最佳轮次 | 4 | 5 |
| 最佳验证准确率 | 63.38% | 71.56% |
| 测试准确率 | 62.67% | 70.00% |
| 测试损失 | 1.0478 | 0.8388 |
| 训练及验证总时间 | 45.2 秒 | 124.2 秒 |
| 训练及验证峰值分配显存 | 143.3 MiB | 170.0 MiB |

此次自注意力组测试准确率高 7.33 个百分点，参数多 1,037（约 0.51%）。两组训练时设备负载变化明显，耗时不适合作为严格速度对照；显存是 PyTorch 的峰值已分配显存，不是整卡占用。

该实验不支持简单地把这次自注意力组优势全部归因于参数更多，但也不能将优势全部归因于注意力：结构、宽度、残差连接和计算量等均不同。单次短训练和先前已用于探索的测试集也限制了结论；可增加多个随机种子、训练轮数和更严格的控制组。完整逐轮数据见 [results.json](parameter_matched_results/results.json)。
