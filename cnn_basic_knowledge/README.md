# CNN 卷积神经网络学习导航

这个目录从今天开始记录 CNN 学习内容。

前面已经学过：

- PyTorch Tensor 基础
- Dataset 与 DataLoader
- autograd 自动求导
- MLP 结构
- 损失函数、优化器、训练流程
- MNIST 手写数字分类

所以 CNN 阶段不再从神经网络零基础开始，而是从图像任务本身开始。

## 参考主线

本阶段参考黑马程序员《神经网络与深度学习》课程中 CNN 图像分类部分的学习顺序：

```text
图像基础知识
-> CNN 基本概念
-> 卷积层
-> 池化层
-> CNN 网络结构
-> 图像分类案例
```

## 当前学习

- `01_图像基础知识.ipynb`：第一课，理解图像、像素、灰度图、RGB 图和图像张量形状。
- `02_CNN概述介绍.ipynb`：第二课，理解 CNN 是什么、为什么适合图像、整体结构由哪些部分组成。
- `03_卷积层运算规则.ipynb`：第三课，理解卷积核如何滑动、如何乘加、stride、padding、输出尺寸和通道变化。
- `05_多通道卷积计算.ipynb`：第五课，理解输入通道、输出通道、多个卷积核和多通道卷积的参数量。
- `06_多卷积核计算.ipynb`：第六课，理解多个卷积核如何并列提取不同特征，以及卷积核个数和输出通道数的关系。
- `07_特征图.ipynb`：第七课，理解特征图是什么、从哪里来、和输出通道的关系，以及浅层和深层特征图的区别。
- `08_池化层原理与运算规则.ipynb`：第八课，理解池化层为什么要压缩特征图、最大池化、平均池化、池化尺寸和通道变化。
- `09_CNN整体网络结构.ipynb`：第九课，把卷积层、激活函数、池化层、展平和全连接层串成完整 CNN 结构。
- `10_Flatten与全连接分类头.ipynb`：第十课，理解特征图如何展平成一维向量，以及全连接分类头如何输出类别分数。
- `11_LeNet经典网络结构.ipynb`：第十一课，理解 LeNet 如何用卷积、池化、展平和全连接完成手写数字分类。
- `12_CNN反向传播与参数更新.ipynb`：第十二课，理解 CNN 中对哪些参数求导、更新哪些参数，以及卷积核共享参数时梯度如何累加。

- `13_CNN图像分类训练流程.ipynb`：第十三课，把图片输入、前向传播、loss、反向传播、优化器更新、epoch 和评估流程串成完整训练闭环。

- `14_CNN图像分类案例总览.ipynb`：第十四课，从数据、模型、loss、优化器、训练和测试几个部分整体认识 CNN 图像分类案例。
- `15_PyTorch中CNN模型结构表示.ipynb`：第十五课，把 Conv2d、ReLU、MaxPool2d、Flatten、Linear 和 forward 对应到 CNN 模型结构与形状变化中。
- `16_CNN-MNIST实战预备.ipynb`：第十六课，进入实战前先整体认识 CNN-MNIST 的任务目标、数据形状、模型结构、训练流程和测试流程。
- `17_CNN-MNIST模型结构拆解.ipynb`：第十七课，在不写代码的前提下逐层拆解 CNN-MNIST 模型结构，重点理解从 `B x 1 x 28 x 28` 到 `B x 10` 的形状变化。

## CNN-MNIST 实战代码

- `cnn_mnist_practice/`：CNN-MNIST 手写数字识别实战代码包。
- `cnn_mnist_practice/cnn_mnist.py`：完整实战主文件，包含数据集导入、DataLoader、CNN 模型、损失函数、Adam 优化器、训练、评估、模型保存和单张图片预测。
- `data/`：MNIST 数据缓存目录，由训练时自动下载生成。
- `models/`：训练产物目录，保存模型参数和训练记录。

`data/` 和 `models/` 属于运行产物，已经在根目录 `.gitignore` 中忽略。
## 第一阶段目标

学完图像基础知识后，先不要急着写 CNN 代码。

你需要先能说清楚：

1. 图片在计算机里为什么可以看成数字矩阵。
2. 什么是像素。
3. 灰度图和 RGB 彩色图有什么区别。
4. 为什么 MNIST 图片可以表示成 `1 x 28 x 28`。
5. 为什么彩色图片通常可以表示成 `3 x H x W`。
